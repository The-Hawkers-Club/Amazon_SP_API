# Amazon SP-API — Solution Provider Documentation Archive

A complete local archive of the Amazon Selling Partner API (SP-API) documentation saved by **The Hawker's Club**, an approved SP-API service provider.

**Not the integration.** The live SP-API integration is
[`The-Hawkers-Club/amzn-api-integration`](https://github.com/The-Hawkers-Club/amzn-api-integration)
(`src/spapi/`, `src/spine/`) — already live, 12 of 12 probed endpoints returning 2xx. This repo is
its offline reference archive, cited by filename. **Start at [`START-HERE.md`](START-HERE.md).**

- **422 documentation pages** (PDF). Coverage is enumerated, not asserted: see
  [`docs/05-archive-index.md`](docs/05-archive-index.md) for every file by SP-API surface and
  [`docs/06-coverage-report.md`](docs/06-coverage-report.md) for which family/version prefixes
  production actually calls are, and are not, documented at this archive's 2026-07-04 capture.
- Each file is one rendered documentation page from the Amazon developer-docs site.
